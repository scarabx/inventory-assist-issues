# Inventory Assist — Bug reports and suggestions

This is the issue tracker for **Inventory Assist**, a Minecraft mod: sort your inventory in one click, then watch your items fly exactly where they belong.
It covers **every version**: Fabric 1.20.1 and Fabric 26.3. The issue form asks which one you play.

**The mod's source is private, so there is no code here.** This repository exists only so that
anyone can report a problem without joining anything.

## Reporting a bug

[Open an issue.](https://github.com/scarabx/inventory-assist-issues/issues/new/choose) Please include:

1. **Which version you play** and the exact Inventory Assist version. Both are in the jar's file name.
2. **Your loader's version:** Fabric Loader and Fabric API.
3. **Other mods installed**, or at least whether you are in a modpack.
4. **What you did and what happened**, in enough detail that someone else could do the same.
5. **A crash report or log** if something went wrong — `.minecraft/crash-reports/` or `logs/latest.log`.

Screenshots or a short video help a lot.
